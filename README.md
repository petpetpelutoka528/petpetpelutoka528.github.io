# 話して聞いて

電話を受けながら片手でメモを取り、困った時の言い回しをすぐ開ける個人用の手帳アプリです。

## 使い方

- **メモ**：上から順に入力。黄色の欄が「次に聞くこと」です。「復唱」で確認用の文が出ます。
- **困った時**：メモを開いたまま、言い回し集を下から表示します。
- **ブック**：言い回しの一覧。「対応を追加」で自分の言い回しを登録できます。
- **履歴**：保存したメモ。タップで伝達メッセージのコピー、状態の変更（未対応→伝達済み→完了）。
- **設定**（履歴タブ）：名乗りに使う会社名・名前、バックアップの書き出し・読み込み。

## GitHub Pages で公開する

1. このフォルダの `index.html` をリポジトリに置く
2. リポジトリの Settings → Pages → Branch を `main` / `root` にして Save
3. 表示された URL をスマホで開き、ホーム画面に追加

## データについて

入力したメモはスマホのブラウザの中（localStorage）だけに保存され、GitHub には送られません。
ブラウザのデータを消すとメモも消えるので、ときどき設定からバックアップを書き出してください。
